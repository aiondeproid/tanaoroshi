# 原料棚卸

紙の「在庫賞味期限管理表」を置き換える、社内ネットワーク用のWebアプリ。タブレットやスマホのブラウザで使う。

## できること

- 名前を選んで入力する（ログインIDは不要）
- 分類ごとに品目を選び、ケース数と端数kgを入れると総重量を自動で計算する
- 期限を入れると自動で判定する
  - 確認月の月末から1ヶ月以上ある：レ
  - 1ヶ月未満：×
  - 期限を過ぎている：×（期限切れ）
- 期限の区分は、賞味期限／使用期限（開封品）／冷凍の使用期限の3つ
- 製造日から期限が決まる品目は、製造日を入れると期限を計算する
- 品目ごとに予想在庫（kg）を手で入れておくと、入力画面に総重量との差を表示する。棚卸の入力前でも入れられる
- ×の品目には対応（製造計画に入れる・移動・廃棄・その他）と、予定日・メモを記録する
- トップ画面に期限警告の件数を出し、一覧から対応を入れられる
- 分類ごとの確認（担当者 → 前工程L → 生産管理 → 品管）を、名前と日時つきで記録する
- 棚卸結果をExcel（.xlsx）で出力する。1枚目が期限警告一覧で、そのあとに分類ごとのシートが続く
- 管理画面（PINが必要）で品目・分類・担当者を編集する。変更はすべて変更履歴に自動で残る

## 起動

`start.bat` をダブルクリックする。初回だけライブラリのインストールが走る。

- 起動するとサーバーは8000番ポートで待ち受ける。タブレットからは `http://<サーバーPC名>:8000` を開く
- Windowsファイアウォールで8000番ポートの受信を許可しておくこと
- 管理者PINは環境変数 `TANAOROSHI_ADMIN_PIN` で設定する。初期値は `1234` なので必ず変更する

### はじめて使うとき

1. 品目マスタを既存のExcelから取り込む。一度実行すればよく、登録済みのコードは上書きしない

   ```
   .venv\Scripts\python tools\import_master.py
   ```

2. 担当者の名前をまとめて登録する。`staff.txt` に1行に1人ずつ名前を書き（書いた順が名前ボタンの並び順になる）、次を実行する。登録済みの名前は飛ばすので、人が増えたら追記して再実行すればよい

   ```
   .venv\Scripts\python tools\import_staff.py
   ```

   あとから1人ずつ足すときは、管理画面の「担当者」タブで追加する

## データ

- すべてのデータは `data\tanaoroshi.db`（SQLite）の1ファイルに入る。バックアップはこのファイルをコピーするだけ
- 変更履歴は、管理画面の「変更履歴」タブで確認できる

## 開発

```
.venv\Scripts\python -m pytest -q
```

期限判定は `app/logic.py` と `app/static/app.js` の2か所に同じ計算がある。変えるときは両方を直すこと。
